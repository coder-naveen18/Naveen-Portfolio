## Email Contact Form Setup

The contact form sends email through EmailJS.

1. Create a `.env` file in the project root.
2. Add these variables:

- `VITE_EMAILJS_SERVICE_ID`
- `VITE_EMAILJS_TEMPLATE_ID`
- `VITE_EMAILJS_PUBLIC_KEY`

3. In your EmailJS template, map the form fields with these names:

- `name`
- `email`
- `message`

After that, the form will send messages directly from the site and show a success message when the email is delivered.
